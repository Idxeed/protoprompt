# Урок 4: рабочая память код-агента

Показывает `WorkingMemory`: цель, разные виды элементов, вытеснение слабого
в холод и возврат через `recall`.

## Запуск

```bash
python examples/tutorials/04_coder_agent/main.py
```

Работает офлайн — сеть и ключи не нужны.

## Что показывает

1. `set_goal` — память «держит курс» на задачу.
2. Разные виды элементов (`file`, `edit`, `note`, `log`) имеют разный вес:
   правка и заметка переживают кучу сырых логов.
3. Когда бюджет переполнен, слабые элементы выселяются в холодную зону
   (`store`) и записываются в `manifest`.
4. `assemble` собирает горячую зону в контекст для модели.
5. `recall` возвращает вытесненное по запросу.

## Идея для эксперимента

- Уберите 30 логов — посмотрите, что горячая зона больше не вытесняется.
- Добавьте `recall_cooldown_steps=10` и сразу вызовите `recall` — карантин
  запретит возврат на первые 10 шагов.
