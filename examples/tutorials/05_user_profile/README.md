# Урок 5: профиль пользователя

Показывает `ProfileManager`: как из сообщений появляются долговечные факты
и предпочтения, как они копятся между сессиями и попадают в промпт.

## Запуск

```bash
python examples/tutorials/05_user_profile/main.py
```

Работает офлайн — сеть и ключи не нужны.

## Что показывает

1. `RuleProfileSource` — детерминированные правила без LLM: определяет
   краткость (`verbosity`), язык и формальность по тексту.
2. `LLMProfileSource` — модель отдала мусор → один ретрай → валидный JSON.
   Русские метки («эксперт», «списки») нормализуются кодеком в канонические
   значения (`expert`, `bullets`), ключи фактов превращаются в слаги
   («Имя» → `imya`).
3. `ProfileManager` — инкрементальное накопление: каждая встреча
   увеличивает `version`, факты копятся, ничего не теряется.
4. Рендер профиля в текст и вставка в `system_prompt` через
   `ContextBuilder`.
5. `reset` (начать заново) и `delete` (удалить профиль).

## Идея для эксперимента

- Замените `InMemoryProfileStore()` на `SqliteProfileStore("users.db")` —
  профили переживут перезапуск.
- Поменяйте очередь ответов в `FakeLLM`: отдайте второй раз мусор — увидите,
  как `LLMProfileSource` сваливается на fallback-правила.
- Добавьте в сигналы `kind="feedback"` и посмотрите, как он выглядит в
  транскрипте источника.
