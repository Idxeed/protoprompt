# Урок 3: LRU-кэш эмбеддингов

Показывает, как `CachedLLMClient` экономит вызовы модели: повторные
тексты берутся из кэша.

## Запуск

```bash
python examples/tutorials/03_embedding_cache/main.py
```

Работает офлайн — сеть и ключи не нужны.

## Что показывает

1. Первый вызов `embed` — модель эмбеддит оба текста.
2. Повторный вызов с тем же списком — оба вектора из кэша, модель не
   зовётся.
3. Частичное совпадение — модель зовётся только за новый текст.
4. Векторы из кэша идентичны исходным (`v1 == v2`).

## Идея для эксперимента

- Уменьшите `capacity` до 1 и добавьте больше текстов — увидите, как LRU
  выкидывает самые старые записи.
- Замените `InMemoryEmbeddingCache` на свою реализацию `EmbeddingCache`
  (например, на диске) — интерфейс всего два метода: `get` и `put`.

Полное объяснение — в [уроке 3 документации](../../../docs/ru/tutorials/03-embedding-cache.md).
