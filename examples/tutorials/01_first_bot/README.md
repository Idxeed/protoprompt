# Урок 1: первая память чат-бота

Бот-географ хранит факты в векторном хранилище и отвечает на вопросы по
смыслу.

## Запуск

```bash
python examples/tutorials/01_first_bot/main.py
```

Работает офлайн — сеть и ключи не нужны.

## Что показывает

1. Как положить факты в память: `store.add(doc_id, chunks, embeddings, metadata)`.
2. Как искать по смыслу: `store.query(embedding, top_k, score_threshold)`.
3. Как работает `score_threshold`: вопрос «Сколько будет 2+2?» не находит
   ничего похожего, хотя в памяти что-то есть.
4. Заглушку `FakeLLM`, которая строит эмбеддинги из слов текста — её можно
   заменить на настоящий клиент (Ollama, OpenAI).

## Идея для эксперимента

- Добавьте свои факты в список `FACTS`.
- Попробуйте `where={"topic": "география"}` — так можно искать только по
  одной теме.

Полное объяснение — в [уроке 1 документации](../../../docs/ru/tutorials/01-first-bot.md).
